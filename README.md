# Electro - C# MVC E-Commerce Project


**Electro** is a simple e-commerce web application built using **ASP.NET MVC**, **Entity Framework**, and **SQL Server**. It allows an **admin** to manage categories and products (with images), while regular users can browse products without admin privileges.  

Live Demo:  
- **User View:** [http://emanalawnah.runasp.net/](http://emanalawnah.runasp.net/)  
- **Admin Panel:** [http://emanalawnah.runasp.net/admin](http://emanalawnah.runasp.net/admin)  

GitHub Repository: [https://github.com/emanAlawnah/Electro](https://github.com/emanAlawnah/Electro)

---

## Features

### Admin Features (Accessible via `/admin`)
- Create, Read, Update, Delete (**CRUD**) operations for **Categories**
- CRUD operations for **Products** with image upload
- Admin panel is separated from user-facing pages
- Only accessible to authorized admins

### User Features
- Browse list of products
- View product details
- No access to admin features
